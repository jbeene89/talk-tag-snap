# Context Trail

Open **Context Trail** from the capture screen or photo toolbar. Start with a wide photo, then add closer photos of the same subject. Each view has a name and a description.

On every view except the last, use **Box the subject** to highlight the part shown in the following photo. **Use centered box** gives you a starting point you can redraw. Tap a highlight to open the closer view. Breadcrumbs and **Wider** restore the surrounding context.

For video, choose **Video frames** or **Record video**, scrub to the moment you want, and use **Add frame to trail** repeatedly. **Done** returns to the trail. The selected time is kept with each frame.

**Preview** checks the linked sequence. **Save trail** creates an editable JSON file. **Save viewer** and **Share trail** create a standalone HTML file: send the file itself and open it in a browser. The viewer includes the photos and works without an account or internet. HTML previews in email and messaging apps may not run the viewer; download the attachment and open it in a browser.

The current draft saves in this device's browser storage. Clearing app/browser data removes it, so export important work. Opening another trail or starting a new one saves the previous trail as a backup file first. Android saves files under Documents/SoupyTag; browser saves use Downloads.

A trail supports up to 12 views and 12 MB. New photos are resized to a maximum of 1600 pixels on the longer side. Existing redactions are baked into a starting photo before it is stored; photo tags remain in the original inspection. New trail photos need redaction before importing if they contain private information. Trail photos are not sent to an AI service.
